# DriveSG dependency & data notes

DriveSG's own prototype source in this package is provided for the user's project use.

External runtime/data dependencies:

- **Three.js 0.160.0** — loaded at runtime from public CDNs; Three.js is MIT licensed.
- **OpenStreetMap / Overpass** — live road and simplified building geometry. The in-game UI includes OpenStreetMap contributor attribution.
- **Nominatim** — used only when the user performs free-text Singapore location search.

No Hop.Earth production assets, branding, private services or proprietary map data are bundled in this package.
